# Tokyo itinerary

iOS Safari travel itinerary with Mapbox Standard, draggable itinerary panel, and current local weather.

## GitHub Pages

Publish these files at the root of the `tokyo-itinerary` repository.
In Settings → Pages, choose **Deploy from a branch**, **main**, and **/(root)**.
The site will be available at https://cianfan0925-cpu.github.io/tokyo-itinerary/.

If the Mapbox Public Token has URL restrictions, allow https://cianfan0925-cpu.github.io.
Only web assets are included; original spreadsheets and backups are excluded.
